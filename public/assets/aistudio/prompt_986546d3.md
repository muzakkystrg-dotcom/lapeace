### 1. SPESIFIKASI STACK TEKNOLOGI
- Framework: Next.js 14+ / 15 (App Router, Server & Client Components yang dipisah secara logis)
- Bahasa: TypeScript (Strict typing dengan interface data yang eksplisit)
- Styling: Tailwind CSS v3.4+ (utility-first, semantic hierarchy, mobile-to-desktop responsive)
- Ikonografi: `lucide-react`
- Font: Inter / Plus Jakarta Sans

### 2. DESIGN TOKENS & COLOR PALETTE (SITAPAK SOVEREIGN CIVIC)
Gunakan palet warna konsisten berikut pada kelas Tailwind CSS:
- Sovereign Dark Green (Navbar, Background Transparansi, Footer Dark): `#083C2E` / `#05241B`
- Emerald Accent (Primary Buttons, Active Badges): `#038D66` (Hover: `#026E4F`)
- Soft Mint / Surface Accent: `#EFFDF4` / `#E9F7EE` / `#CFDDD5`
- Primary Surface / Background: `#F8FAF9` atau `#FFFFFF`
- Card Container: `#FFFFFF` dengan `border border-emerald-100/70 shadow-sm hover:shadow-md transition-all`
- Text Hierarchy:
  - Text Dominan/Heading: `#15211C`
  - Text Muted/Subtle: `#5A6862`
  - Text On-Dark: `#FFFFFF` dan `#A0D1BD` (emerald tint)

4. Kode harus siap dijalankan langsung di proyek Next.js tanpa error kompilasi.
